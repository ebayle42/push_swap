# push_swap

## Description

push_swap, because sorting with two stacks and eleven moves is more fun than qsort()

The goal is to sort a list of integers in stack `a` using an empty stack `b` and a
limited set of operations (`sa` `sb` `ss` `pa` `pb` `ra` `rb` `rr` `rra` `rrb` `rrr`),
while printing the shortest possible list of operations

- `main.c` : main file of the project, parses, measures the disorder and launches the sort
- `push_swap.h` : .h file of the project, contains the structures and all the prototypes
- `srcs/pushswap_parse.c` : reads the flags (`--simple`, `--medium`, `--complex`, `--adaptive`, `--bench`)
- `srcs/parse_num.c` : converts the arguments to int, detects errors and duplicates, converts values to ranks
- `srcs/disorder.c` : computes the disorder of the stack
- `srcs/ops_*.c` : the eleven operations
- `srcs/utils.c` and `srcs/utils_second.c` : helpers (min, max, rotation cost, sort of three)
- `srcs/min_max.c` : simple strategy
- `srcs/range.c` : medium strategy
- `srcs/quick_entry.c` and `srcs/quick_sort.c` : complex strategy
- `srcs/run_algo.c` : chooses the strategy
- `srcs/bench.c` : prints the statistics of `--bench`

Compile:

```sh
make        # builds libft, ft_printf and push_swap
```
```sh
make clean  # removes object files
```
```sh
make fclean # removes object files, the libraries and push_swap
```
```sh
make re     # fclean + all
```

Use:

```sh
./push_swap 2 1 3 6 5 8
```
```sh
./push_swap --medium 2 1 3 6 5 8
```
```sh
./push_swap --bench $(shuf -i 1-1000 -n 100) > /dev/null
```
```sh
ARG=$(shuf -i 1-1000 -n 100 | tr '\n' ' '); ./push_swap $ARG | ./checker_linux $ARG
```

Each number must be a separate argument, `Error` is printed on stderr for a non integer,
an int overflow or a duplicate, and nothing is printed if the stack is already sorted

## Algorithms

Before sorting, every value is replaced by its rank (`0` to `n - 1`), the order stays the
same but the median of a group and the limits of a range become simple to compute

- `--simple` : `minmax_sort`, **O(n²)**, takes out the min or the max, whichever is
  cheaper to bring to the top, mins go to the bottom of `b` and maxs stay on top, then
  `b` is pushed back in order
- `--medium` : `range_sort`, **O(n√n)**, pushes to `b` the values inside a sliding window
  of width `√(2n)`, the smallest ones go to the bottom of `b`, then the max of `b` is
  pushed back to `a` until `b` is empty
- `--complex` : `quick_sort`, **O(n log n)**, recursive quicksort on both stacks with the
  median as pivot, groups of three or less are sorted by hand
- `--adaptive` (default) : chooses depending on the disorder

| Disorder | Strategy |
|---|---|
| 5 numbers or less, or disorder < 0.2 | simple |
| disorder < 0.5 | medium |
| disorder ≥ 0.5 | complex |

## Disorder

The disorder is the proportion of pairs that are in the wrong order

```
disorder = number of pairs (i < j) with a[i] > a[j] / (n × (n − 1) / 2)
```

`0` means sorted, `1` means sorted in reverse, a random list is around `0.5`
